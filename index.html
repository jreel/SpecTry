SpecTry

Spectroscopy practice tool for CHM 251 (Organic Chemistry I)

Interactive practice with IR, MS, ¹H NMR, and ¹³C NMR spectra. Built for students learning to interpret spectra and connect them to molecular structure.

Practice Questions

  • App for Practice Questions prototype
    Currently contains only one question type: identify which functional group produced a particular IR signal

Spectrum Viewers

  • Mass Spectrum (MS) Viewer prototype
    Stick plot with molecular ion and isotope pattern labels
  • IR Spectrum Viewer prototype
    Continuous transmittance trace with functional group labels
  • ¹³C NMR Viewer prototype
    Stick plot with chemical shift labels and assignments
  • ¹H NMR Viewer prototype
    Simulated NMR trace with multiplet patterns, shift, and integration

Authoring Tools

  • Spectroscopy Converter active
    Convert SDBS/NIST data into compound JSON files for the practice tool
SpecTry is an open educational resource for organic chemistry spectroscopy practice.
